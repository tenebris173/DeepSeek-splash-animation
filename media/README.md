# 示例素材

开屏动画的**开箱即用素材**。你可以：

- 直接把素材文件夹指到这里（设置页 →「选择文件夹…」）；
- 或者把想要的文件复制到你自己的素材目录：`$DSH_HOME/dsh-splash-animation/media/`。

> ⚠️ 如果你是通过 `dsh plugin add github:...` 装的插件，这个目录会位于 `node_modules` 里面。**别把自己的文件放进来**——包管理器下次安装会把它整个重建。要么复制出去用，要么把文件夹指向你自己的目录。

| `开机动画3-12秒.mp4` | 12.4s | 1280×720 | 同上 | MIT |

全部为 **H.264 + AAC**——这是刻意的：Chromium 默认不解 HEVC(H.265)，而 HEVC 能不能播取决于对方系统有没有装扩展、显卡支不支持硬解。发出去给别人用的素材不该有这种不确定性。

## 关于转码

`PRTS启动-10秒.mp4` 和 `普鲸声音重叠.mp4` 的原始文件是 **4K HEVC**，在本仓库里换成了 **1080p H.264**：

| 原始 | 现在 |
|---|---|
| `PRTS启动4K 10S.mp4`，3840×2160 HEVC，2.4 MB | `PRTS启动-10秒.mp4`，1920×1080 H.264，0.5 MB |
| `普鲸声音重叠.mp4`，3840×2160 HEVC，21.9 MB | 1920×1080 H.264，5.0 MB |

开屏动画铺满屏幕时 1080p 已经足够，而这个改动让仓库小了 19 MB、并且保证任何机器都能播。转码命令：

```bash
ffmpeg -i input.mp4 -c:v libx264 -crf 20 -preset medium -pix_fmt yuv420p \
  -vf scale=-2:1080 -movflags +faststart -c:a aac -b:a 160k output.mp4
```
